# Toowong Cemetery images

Images about Toowong Cemetery and the people remembered there.

Created to:

- be an archive of high-resolution images
- remove images from https://www.fotc.au so it stays under the 1GB size limit for sites published using GitHub Pages

Licensing for images is in the README.md file in each folder. 

## How to reference files

Reference a file using the format `https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/FOLDER/FILENAME.jpg`

For example: 

Reference `https://github.com/1871fotc/images/blob/main/demolished-toowong-headstones/1-44-18-nevill/1-44-18-nevill-headstone.jpg` 

using `https://raw.githubusercontent.com/1871fotc/images/main/demolished-toowong-headstones/1-44-18-nevill/1-44-18-nevill-headstone.jpg`

## Updating the fotc website

For the page https://www.fotc.au/headstones/demolished-toowong-headstones/ that uses https://github.com/1871fotc/1871fotc.github.io/blob/main/snippets/demolished-toowong-headstones.html 

change the photo and report link prefix from `../../assets/` to `https://raw.githubusercontent.com/1871fotc/images/main/`
