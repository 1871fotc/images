## Structure

Each folder is named using the `Portion` - `Section` - `Grave` addressing scheme followed by the first interred person's `last name`.

Each folder usually contains two files:

- a photo of the gravesite before it was demolished
- an image of the correspondence sent to the family informing them of the potential demolition
